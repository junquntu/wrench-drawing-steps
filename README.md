# 扳手 · 尺规作图分步图解

按图样《扳手.jpg》解构的**双头开口扳手**平面图形，拆成 **15 个可复现的尺规作图步骤**。
每一步都给出：**圆心在哪里、距基准线多远、半径多少、从哪一点划到哪一点、用什么线型**，
并配尺寸线与尺寸界线。全部图形与声音由代码生成，**构建在 GitHub Actions 上完成**。

* 成片：`docs/扳手-尺规作图.mp4`（1920×1080 / 30fps / 约 2 分 20 秒，含配乐与音效）
* 分步静帧：`docs/step01.png … step15.png`
* 总览：`docs/总览-15步.png`
* 海报：`docs/poster.png`

## 一、图样解读（文字解析）

### 1. 定形尺寸

| 尺寸 | 含义 | 用在哪个图元 |
|---|---|---|
| R14 | 右端头外圆 | 以 O1 为圆心的整圆 |
| R18 | 左端头外圆 | 以 O2 为圆心的整圆 |
| R16 | 左端头**开口侧**外弧 | 与开口底同心（壁厚 2） |
| R8 | 右开口底圆弧 | 以 C1 为圆心 |
| R14 | 左开口底圆弧 | 以 C2 为圆心（图样标注，见下方说明） |
| 12 | 右开口宽度 | 两侧面间距 |
| 14 | 左开口宽度 | 两侧面间距 |
| R4 | 手柄槽右端半圆 | 以 S1 为圆心 |
| R5 | 手柄槽左端半圆 | 以 S2 为圆心 |
| R5 | 过渡圆角 | 端头与手柄 4 处 + 左端 R18/R16 之间 2 处 |
| 1.5 | 手柄壁厚 | 槽侧边 → 手柄外缘 |

### 2. 定位尺寸

| 尺寸 | 含义 |
|---|---|
| 120 | 两开口中心 O1、O2 的距离（沿水平基准线量） |
| 4 | 右开口底圆心 C1 距 O1（沿 15° 方向线） |
| 6 | 左开口底圆心 C2 距 O2（沿 15° 方向线） |
| 74 | 手柄槽两端半圆圆心 S1、S2 的距离 |
| 15° | 开口方向线与轴线夹角（两端对称） |

### 3. 线段分析

| 类别 | 图线 | 缺几个条件 |
|---|---|---|
| **已知线段** | 右端头 R14、左端头 R18、两条 15° 方向线 | 0 |
| **中间线段** | 开口底弧 R8 / R14、R16 外弧、四条开口侧面 | 1（圆心在方向线上） |
| **连接线段** | 槽端半圆与两侧边、R5 过渡圆角（6 处） | 2（只给半径，靠相切定圆心） |

> 作图顺序固定为：**基准线 → 已知线段 → 中间线段 → 连接线段 → 修剪 → 描深**。

### 4. 图样内部矛盾的取舍（重要）

手绘图样里有三处尺寸彼此不闭合，作图时按"几何可作、轮廓闭合"优先处理，并在片子里讲清楚：

1. **开口底弧与开口宽度**
   开口宽 12（右）/14（左），而开口底弧标 R8 / R14。若两侧面与底弧**相切**，
   底弧半径只能是半宽（6 / 7）。图样画的是"底面比口部略大"的弧形，
   所以本片按 **底弧半径 = 半宽（R6 / R7）相切** 作图，标注仍沿用图样的 R8 / R14。
2. **左端头 R16 与 R18**
   两弧同心不可能，本片按图样意图：R16 与开口底同心（等壁厚 2），
   与 R18 外圆相交，交点两侧用 **R5 圆角**收口（图样左端确有两处 R5 标注）。
3. **74 与 120**
   74 为槽长（两端圆心距），120 为两端头中心距；槽按 120 居中布置，
   槽端与手柄圆角之间留 3～5mm，与图样观感一致。

### 5. 几何解算（mm，原点 O1，X 向右，Y 向上）

```
O1 = (0, 0)                  O2 = (-120, 0)
u  = 15° 方向                C1 = O1 + 4u = (3.864, 1.035)
                             C2 = O2 + 6u = (-125.796, -1.553)
S1 = (-23, 0)                S2 = (-97, 0)             （74 居中）
R18 与 R16 交点 Q1 / Q2      |O2Q| = 18, |C2Q| = 16, |O2C2| = 6
R5 圆角圆心 F               |F - 端头中心| = R外圆 + 5，且 F 到手柄边线距离 = 5
总长 ≈ 148.7
```

## 二、15 步作图

| # | 步骤 | 关键操作（圆心 / 半径 / 尺寸） |
|---|---|---|
| 01 | 画基准线 | 水平轴线；O1 处竖线；自 O1 量 **120** 得 O2 竖线；标注 120 |
| 02 | 右端头外圆 **R14** | 针尖插 O1，张开 14，画整圆；半径尺寸自圆心引出 |
| 03 | 左端头外圆 **R18** | 针尖插 O2，张开 18，画整圆 |
| 04 | **15° 方向线** | 过 O1、O2 各作 15° 细点画线（两端对称）；角度尺寸 15° |
| 05 | 开口底圆心 **C1、C2** | 沿方向线自 O1 量 **4** 得 C1；自 O2 量 **6** 得 C2 |
| 06 | 开口底弧 **R8 / R14** | 针尖插 C1 张 8；针尖插 C2 张 14；各画到与两侧面的交点 |
| 07 | 开口两侧面 | 过底弧两端点作方向线的平行线，间距 **12** / **14**，与端头外圆交出角点 |
| 08 | 左端头 **R16** 外弧 + **R5** 过渡 | 针尖插 C2 张 16；与 R18 相交后用 R5 圆角收口（圆心距 O2 为 13、距 C2 为 11） |
| 09 | 槽端圆心 **S1、S2** | O1O2 中点作竖线；向两侧各量 37，总长 **74** |
| 10 | 槽端半圆与两侧边 | R4（S1）、R5（S2）+ 两条外公切线（槽宽 8→10，锥形） |
| 11 | 手柄两侧 **1.5** | 槽侧边向外平移 1.5 得手柄外缘（等壁厚） |
| 12 | R5 圆角（右端头） | 辅助弧 **R=14+5=19** + 平移 5 的辅助线 → F1；张 5 划弧；下侧同理 F2 |
| 13 | R5 圆角（左端头） | 辅助弧 **R=18+5=23** + 平移 5 → F3；张 5 划弧；下侧同理 F4 |
| 14 | 修剪 | 擦 R14 开口段、R18 手柄段、手柄边线两端、求圆心的辅助弧与辅助线 |
| 15 | 描深 | 粗实线描深轮廓（粗:细≈3:1），核对全部尺寸 |

### 弧怎么"划"（片子里的表现）

圆弧不用圆规图标，而是**一根"半径尺寸线"绕圆心转动**扫出：半径线一端钉在圆心（画十字），
另一端带箭头指在圆周上，转过多少度就划出多少度，转完即停、**同一条弧不划第二遍**；
多余部分在"修剪"一步**淡出擦除**，而不是重画。

## 三、工程结构

```
wrench/
  geom.py      尺寸与相切条件解算（全部圆心、切点、交点）
  model.py     15 步图元清单 + 时间轴（每步每图元的出现时刻）
  render.py    帧渲染器（图纸版式、图元动画、尺寸线动画、文字面板、片头片尾）
  audio.py     程序化配乐与音效（铅笔声、圆规声、步骤铃音）
  build.py     构建入口：静帧 / 总览 / 音频 / 视频
  draw.py      超采样画布（虚线、圆弧、箭头、旋转文字、透明混色）
  preview.py   单帧预览（调版式用）
.github/workflows/build.yml   云端构建（GitHub Actions）
```

### 构建

```bash
pip install pillow numpy imageio-ffmpeg
python wrench/build.py --preview     # 静帧 + 24s 样片
python wrench/build.py --full        # 全片
```

云端：push 到 `main` 自动构建；或在 Actions 页 `workflow_dispatch` 选 `preview` / `full`。
产物在 `docs/`，同时上传 artifact `wrench-drawing-steps`。
