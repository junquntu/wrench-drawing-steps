# 扳手 · 尺规作图分步图解

按图样《扳手.jpg》解构的**双头开口扳手**平面图形，拆成 **15 个可复现的尺规作图步骤**，
每一步都给出：**圆心在哪里、距基准线多远、半径多少、从哪一点划到哪一点、用哪种线型**，
并配尺寸线与尺寸界线。全部图形由代码生成（Pillow 超采样 + 程序化配乐），
**构建在 GitHub Actions 上完成**。

* 成片：`docs/扳手-尺规作图.mp4`（1920×1080 / 30fps / 约 2 分 20 秒，含配乐音效）
* 分步静帧：`docs/step01.png … step15.png`
* 总览：`docs/总览-15步.png`
* 片头 / 片尾海报：`docs/poster.png`

## 一、图样分析

### 1. 定形尺寸（决定形状大小）

| 尺寸 | 含义 | 用在哪个图元 |
|---|---|---|
| R14 | 右端头外圆半径 | 以 O₁ 为圆心的整圆 |
| R18 | 左端头外圆半径 | 以 O₂ 为圆心的整圆 |
| R16 | 左端头**开口侧**外弧半径 | 与 R14（开口底）**同心** |
| R8 | 右开口底圆弧 | 以 C₁ 为圆心 |
| R14 | 左开口底圆弧 | 以 C₂ 为圆心 |
| 12 | 右开口宽度 | 两条侧面间距 |
| 14 | 左开口宽度 | 两条侧面间距 |
| R4 | 手柄槽右端半圆 | 以 S₁ 为圆心 |
| R5 | 手柄槽左端半圆 | 以 S₂ 为圆心 |
| R5 | 端头与手柄的过渡圆角 | 共 4 处 |
| 1.5 | 手柄壁厚 | 槽侧边到手柄外缘 |

### 2. 定位尺寸（决定圆心位置）

| 尺寸 | 含义 |
|---|---|
| 120 | 两开口中心 O₁、O₂ 的距离（沿水平基准线量） |
| 4 | 右开口底圆心 C₁ 距 O₁（沿 15° 方向线量） |
| 6 | 左开口底圆心 C₂ 距 O₂（沿 15° 方向线量） |
| 74 | 手柄槽两端半圆圆心 S₁、S₂ 的距离 |
| 15° | 开口方向线与轴线的夹角（两端对称） |

### 3. 线段分析（决定作图顺序）

| 类别 | 图线 | 缺几个条件 |
|---|---|---|
| **已知线段** | 右端头 R14、左端头 R18、两条 15° 方向线 | 0（尺寸齐全，直接画） |
| **中间线段** | 开口底弧 R8 / R14、R16 外弧、四条开口侧面 | 1（圆心在方向线上） |
| **连接线段** | 槽端半圆与两侧边、四条 R5 过渡圆角 | 2（只给半径，靠相切定圆心） |

> 顺序固定为：**基准线 → 已知线段 → 中间线段 → 连接线段 → 修剪 → 描深**。
> 顺序错了，后面每一条弧都要回头改。

### 4. 几何解算（mm，原点 O₁，X 向右，Y 向上）

```
O₁ = (0, 0)              O₂ = (-120, 0)
u  = 15° 方向            C₁ = O₁ + 4u = (3.864, 1.035)
                         C₂ = O₂ + 6u = (-125.796, -1.553)
S₁ = (-23, 0)            S₂ = (-97, 0)          （74 居中）
R14 与 R16 交点 Q₁, Q₂    |O₂Q| = 18, |C₂Q| = 16, |O₂C₂| = 6
R5 圆角圆心 F：|F-O| = R外圆 + 5，且 F 到手柄边线距离 = 5
总长 = 148.7（左端 R18 最左点 → 右端开口角点）
```

## 二、15 步作图（每步都标圆心、半径、尺寸线）

| # | 步骤 | 关键操作 |
|---|---|---|
| 01 | 画基准线 | 水平轴线；O₁ 处竖线；自 O₁ 量 **120** 得 O₂ 竖线；尺寸 120 |
| 02 | 右端头外圆 **R14** | 针尖插 O₁，张开 14，画整圆；半径尺寸自圆心引出 |
| 03 | 左端头外圆 **R18** | 针尖插 O₂，张开 18，画整圆 |
| 04 | **15° 方向线** | 过 O₁、O₂ 各作 15° 细点画线（两端对称）；角度尺寸 15° |
| 05 | 开口底圆心 **C₁、C₂** | 沿方向线自 O₁ 量 **4** 得 C₁；自 O₂ 量 **6** 得 C₂ |
| 06 | 开口底弧 **R8 / R14** | 针尖插 C₁ 张 8；针尖插 C₂ 张 14；各画约 180° |
| 07 | 开口两侧面 | 与 R8 相切、间距 **12**；与 R14 相切、间距 **14**；与端头外圆交于角点 |
| 08 | 左端头 **R16** 外弧 | 仍以 C₂ 为圆心，张 16；与 R18 交于 Q₁、Q₂（后壁等厚 2mm） |
| 09 | 槽端圆心 **S₁、S₂** | O₁O₂ 中点作竖线；向两侧各量 37，总长 **74** |
| 10 | 槽端半圆与两侧边 | R4（S₁）、R5（S₂）+ 两条外公切线（槽宽 8→10，锥形） |
| 11 | 手柄两侧 **1.5** | 槽侧边向外平移 1.5 得手柄外缘（等壁厚） |
| 12 | R5 圆角（右） | 辅助弧 **R=14+5=19** + 平移 5 的辅助线 → F₁；张 5 划弧；下侧同 |
| 13 | R5 圆角（左） | 辅助弧 **R=18+5=23** + 平移 5 → F₃；张 5 划弧；下侧同 |
| 14 | 修剪 | 擦 R14 开口段、R18 手柄段、手柄边线两端、求圆心的辅助线 |
| 15 | 描深 | 粗实线描深轮廓（粗:细≈3:1），核对全部尺寸 |

### 每条弧怎么"划"（视频里的表现方式）

圆弧不用圆规图标，而是**一根"半径尺寸线"绕圆心转动**扫出：
半径线一端钉在圆心（画十字），另一端带箭头指在圆周上，转过多少度就划出多少度，
转完即停、**同一条弧不划第二遍**；多余部分在"修剪"一步**淡出擦除**，而不是重画。

## 三、工程结构

```
wrench/
  geom.py      尺寸与相切条件解算（全部圆心、切点、交点）
  model.py     15 步图元清单 + 时间轴（每步每图元的出现时刻）
  render.py    帧渲染器（图纸版式、图元动画、尺寸线动画、文字面板）
  audio.py     程序化配乐与音效（铅笔声、圆规声、步骤铃音）
  build.py     构建入口：静帧 / 总览 / 音频 / 视频
  draw.py      超采样画布（虚线、圆弧、箭头、旋转文字、透明混色）
.github/workflows/build.yml   云端构建（GitHub Actions）
```

### 构建

```bash
# 本地（可选）
pip install pillow numpy imageio-ffmpeg
python wrench/build.py --preview     # 静帧 + 24s 样片
python wrench/build.py --full        # 全片

# 云端：push 到 main 自动构建；或在 Actions 页 workflow_dispatch 选 preview / full
```

产物：`docs/` 下的分步图、总览、视频；Actions 里同时上传 artifact `wrench-drawing-steps`。
